# Yascore

Локальный сервер голосового помощника. Колонка для него необязательна: это микрофон, динамик и уже установленный плеер. Имя помощника, промпты, адреса и пути задаются в одном файле.

Проект неофициальный и с Яндексом не связан. В репозитории нет программ, моделей и ключей Яндекса. Товарные знаки принадлежат их владельцам.

Код открыт: его можно читать, запускать у себя, менять и присылать правки пул-реквестом. ## Настройка

Скопируйте образец и правьте только его:

```sh
cp config.yml.example config.yml
```

Код читает `config.yml`. Образец сам по себе сервер не запускает. В файле три секции:

- `core` — имя, промпты, распознавание, модель, голос, адрес сервера
- `skills` — хосты и каталоги погоды, валюты, поиска, настроения и музыки
- `logs` — уровень и пути журналов

Имя записано один раз, в `core.name`. В текстах промптов пишите `{name}`: при запуске оно подставляется. Дополнительные услышанные слова, включая падежи, добавляются в `core.wake.words`. Пустой список значит одно слово — имя.

Пустой хост ядра (`core.stt.url`, `core.llm.base_url`, `core.tts.url`, `core.server.listen`, `core.server.public_base`, `core.skills_socket`) останавливает запуск и называет поле. Пустой хост скилла выключает только этот скилл и пишет предупреждение.

`core.server.public_base` — адрес компьютера в сети, по которому колонка скачивает MP3. Адрес `127.0.0.1` колонка открывает у себя.

`logs.level` — `DEBUG`, `INFO`, `WARNING` или `ERROR`. На `DEBUG` пишутся подробный журнал действий и wav услышанной фразы в `logs.audio`. На `INFO` и выше эти файлы не пополняются. MP3 ответа в `core.server.audio_dir` пишется всегда: без него колонке нечего произносить.

Глубина диалога, паузы и доля громкости музыки, пока говорит помощник, тоже в `core`.

## Запуск

Из корня репозитория, когда `config.yml` уже заполнен:

```sh
make up
```

Это собирает `bin/yascore`, поднимает синтез по `core.tts.url`, если он ещё не отвечает, и перезапускает user-unit `yascore.service`. Для голоса в `config.yml` нужны `core.tts.python` и `core.tts.model`. Модель берётся из `core.llm`.

Проверка — адрес из `core.server.listen`. Если там `0.0.0.0`, с этой машины открывайте `127.0.0.1` и тот же порт. Синтез проверяется по `core.tts.url`.

Колонка, если `skills.youtube_music.host` заполнен:

```sh
make column
scripts/point-mini2.sh
scripts/local-voice.sh
```

Скрипты берут хост, пути и промпт моста из `config.yml`.

## Проверки

```sh
make test
make integration
```

`make test` — юнит-тесты. `make integration` — автотесты с тегом `integration`: они пропускают шаг, если воркер или сеть недоступны.
