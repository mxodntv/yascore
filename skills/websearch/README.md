# websearch

## Описание

Скилл поиска в интернете. Регистрирует инструмент `web_search` с описанием «Поиск в интернете: факты, новости, курсы, кто/когда/сколько.». Обязательный параметр — строка `query`. Подсказки маршрутизации: «найди», «погугли», «курс», «новост», «кто такой», «сколько», «поиск».

Запрос уходит POST-формой `q` на `https://html.duckduckgo.com/html/` (`Endpoint`). Ответ — до пяти строк «заголовок. сниппет».

## Состояние

Рабочий обработчик, включённый в процесс. `Register` поднимает соединение через `protocol.Run` (флаги звука и медиа остаются выключенными). Ядро вызывает эту регистрацию из `skillRegs` в `cmd/yascore/init.go`. Вызов инструмента разбирает JSON-поле `query` и передаёт его в `Search`.

## Разработано

- `Search`: пробельный запрос возвращает «пустой запрос» без HTTP. Иначе POST с `Content-Type: application/x-www-form-urlencoded` и `User-Agent: yascore`. Тело читается не дальше 1 МиБ. Статус HTTP от 400 и сбой запроса возвращают ошибку «поиск не удался». Успешное тело отдаётся в `ParseResults`.
- `ParseResults`: до пяти заголовков `class="result__a"` и сниппетов `class="result__snippet"`. Из текста убираются теги; подставляются `&amp;`, `&quot;` и `&#x27;`. Пустой разбор возвращает «ничего не нашлось».
- `handle`: имя инструмента игнорируется. Ошибка `json.Unmarshal` отбрасывается; при битом JSON запрос получается пустым.

## Проверено

`skills/websearch/search_test.go`:

- `TestParseResults` — заголовок «Курс доллара» и сниппет «90 рублей» дают строку «Курс доллара. 90 рублей».
- `TestParseResultsEmpty` — HTML без таких классов даёт «ничего не нашлось».
- `TestSearchEmptyQuery` — запрос из пробелов даёт «пустой запрос» и `err == nil`.

`autotests/skills/websearch/websearch_test.go` (`//go:build integration`):

- `TestSearchFixture` — `Search` ходит на локальный `httptest` с одной парой заголовок/сниппет и сравнивает ответ с «Курс. 90 рублей».

## Не реализовано

Отдельной ошибки на битый JSON нет: `handle` игнорирует ошибку разбора. Других заглушек в пакете нет: поиск, разбор HTML и регистрация написаны.
