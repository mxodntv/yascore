# Валюта

## Описание

Обычный навык `currency`. Регистрация идёт через `protocol.Run`: звука нет, флаг media выключен. Средняя кнопка колонки этот навык не продолжает.

Инструмент один — `currency_rate`. Он называет курс валюты по дневному списку Центробанка России. База всегда рубль, базовую валюту навык не спрашивает. Ответ — короткая русская фраза, её говорят как есть. Для одного доллара при курсе 92,40 это «Доллар стоит девяносто два рубля».

Подсказки для модели: «валют», «доллар», «евро», «юан», «тенге», «курс».

## Состояние

Курс читается запросом `GET {API}/scripts/XML_daily.asp`. Адрес, каталог и таймаут задаются в `skills.currency` в `config.yml`.

Сохранённый код лежит в `skills/currency/data/default.json`, документ `default`, поле `code`. В репозитории сейчас записан `USD`. Код один. Старый общий `data/skills.json` при открытии каталога по умолчанию копируется один раз; новые записи в него не идут.

Пустой `currency` при пустом документе даёт «Какую валюту запомнить?» и в банк не ходит. Первая названная валюта записывается. Позже названная валюта — курс на один раз, сохранённый код остаётся. `remember: true` меняет код, когда пользователь просит запомнить или сменить валюту. Вопрос «какая валюта по умолчанию» — пустой `currency` и `remember: false`: документ не переписывается.

Сумма округляется до целого рубля и произносится словами. Номинал больше единицы звучит отдельно: «Сто тенге стоят восемнадцать рублей». Про рубль навык отвечает «Рубль и есть базовая валюта.»

## Разработано

- Инструмент `currency_rate` с полями `currency` (код или название, пусто — сохранённая валюта) и `remember` (только по просьбе запомнить или сменить валюту).
- Дневной список ЦБ: XML, в том числе windows-1251, и JSON, если тело начинается с `{`. В списке ищется код. Номинал и сумма в рублях берутся из бюллетеня.
- Разбор названий: «доллар», «евро», «юань», «тенге» и другие алиасы, а также трёхбуквенный код. Незнакомое слово отсекается локально фразой «Не знаю такую валюту.» Код, которого нет в дневном списке, даёт ту же фразу после ответа банка.
- Речь: целое число рублей прописью, согласование «рубль / рубля / рублей». Для известных кодов свои формы («Доллар», «Сто … тенге»); иначе имя из бюллетеня.
- Память: первая названная валюта пишется в `default.json`. Ошибка банка и незнакомая валюта код не сохраняют. Сбой записи отвечает «Не удалось запомнить валюту.» Сбой курса и кривой JSON аргументов отвечают «Не удалось узнать курс.» Курс навык не выдумывает. Вызов инструмента возвращает фразу, а не ошибку протокола.

## Проверено

Тесты в `skills/currency/skill_test.go`. Сервер локальный (`httptest`), путь `/scripts/XML_daily.asp`. Живой `www.cbr.ru` эти тесты не вызывают.

- `TestXMLFixtureSpeaksRubles` — XML: «доллар» даёт «Доллар стоит девяносто два рубля» и один запрос; «тенге» даёт «Сто тенге стоят восемнадцать рублей».
- `TestJSONFixtureSpeaksRubles` — JSON через `Handle` с именем `currency_rate` и `{"currency":"USD"}` даёт ту же фразу про доллар.
- `TestWindows1251Fixture` — XML в windows-1251 с именем «Доллар» даёт ту же фразу.
- `TestUnknownCurrency` — «абракадабра» даёт «Не знаю такую валюту.», банк не вызывается, код не пишется; «ZZZ» вызывает банк один раз, та же фраза, курса в ответе нет.
- `TestHTTPError` — статус 502 даёт «Не удалось узнать курс.», курса в ответе нет, при `remember` код не пишется.
- `TestFirstUseAskThenSavedDefault` — пустой `currency` даёт «Какую валюту запомнить?» без запроса в банк; «доллар» сохраняется как `USD`; повторный пустой вызов снова говорит доллар и код не меняет.
- `TestNamedCurrencyDoesNotReplaceDefault` — после доллара «евро» даёт «Евро стоит сто рублей» и оставляет `USD`; пустой вопрос снова про доллар.
- `TestRememberChangesDefault` — `{"currency":"евро","remember":true}` меняет код на `EUR` и говорит «Евро стоит сто рублей»; пустой вопрос говорит евро и документ не переписывает.
- `TestSettingsFromEnv` — из окружения читаются база API, каталог и таймаут 3,5 с.

## Не реализовано

- Курса на дату нет: читается только дневной список `XML_daily.asp`.
- Пересчёта одной иностранной валюты в другую нет: аргументов две валюты, ответ всегда в рублях.
- Копейки в фразе нет: сумма округляется до целого рубля.
- В документе одно поле `code`. Списка валют по умолчанию нет.
- Дневной бюллетень между вызовами не запоминается: каждый курс — новый HTTP-запрос.
