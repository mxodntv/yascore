# rutube

## Описание

Скилл видео Rutube. Регистрирует на шине инструмент `play_rutube` с описанием «Включить видео на Rutube.». Обязательный параметр — строка `query`. Подсказки маршрутизации: «рутуб», «rutube».

## Состояние

Заглушка, уже включённая в процесс. `Register` поднимает соединение через `protocol.Run` (флаги звука и медиа остаются выключенными). Ядро вызывает эту регистрацию из `skillRegs` в `cmd/yascore/init.go`. На вызов отвечает `protocol.NotReady`: текст «скилл rutube ещё не подключён», без ошибки.

## Разработано

- Имя скилла на шине: `rutube`.
- Один инструмент `play_rutube`, схема параметра `query` (string, required).
- Подсказки: «рутуб», «rutube».
- Обработчик — общий `protocol.NotReady("rutube")`.

## Проверено

Тестов пакета нет: в `skills/rutube` нет файлов `*_test.go`.

## Не реализовано

Поиск ролика и включение видео. Аргумент `query` не читается, плеер не вызывается.
