# vkvideo

## Описание

Скилл видео VK. Регистрирует инструмент `play_vk_video` с описанием «Включить видео VK.». Обязательный параметр — строка `query`. Подсказки маршрутизации: «вк видео», «vk video».

## Состояние

Заглушка, уже включённая в процесс. `Register` поднимает соединение через `protocol.Run` (флаги звука и медиа остаются выключенными). Ядро вызывает эту регистрацию из `skillRegs` в `cmd/yascore/init.go`. На вызов отвечает `protocol.NotReady`: текст «скилл vkvideo ещё не подключён», без ошибки.

## Разработано

- Имя скилла на шине: `vkvideo`.
- Один инструмент `play_vk_video`, схема параметра `query` (string, required).
- Подсказки: «вк видео», «vk video».
- Обработчик — общий `protocol.NotReady("vkvideo")`.

## Проверено

Тестов пакета нет: в `skills/vkvideo` нет файлов `*_test.go`.

## Не реализовано

Поиск ролика и включение видео VK. Аргумент `query` не читается, плеер не вызывается.
