# smarthome

## Описание

Скилл умного дома. Регистрирует инструмент `home` с описанием «Управление умным домом через Home Assistant.». Обязательный параметр — строка `command`. Подсказки маршрутизации: «свет», «дом», «шторы».

## Состояние

Заглушка, уже включённая в процесс. `Register` поднимает соединение через `protocol.Run` (флаги звука и медиа остаются выключенными). Ядро вызывает эту регистрацию из `skillRegs` в `cmd/yascore/init.go`. На вызов отвечает `protocol.NotReady`: текст «скилл smarthome ещё не подключён», без ошибки.

## Разработано

- Имя скилла на шине: `smarthome`.
- Один инструмент `home`, схема параметра `command` (string, required).
- Подсказки: «свет», «дом», «шторы».
- Обработчик — общий `protocol.NotReady("smarthome")`.

## Проверено

Тестов пакета нет: в `skills/smarthome` нет файлов `*_test.go`.

## Не реализовано

Клиента Home Assistant в пакете нет. Аргумент `command` не читается, устройства не вызываются.
