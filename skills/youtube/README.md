# youtube

## Описание

Скилл видео YouTube. Регистрирует инструмент `play_youtube` с описанием «Включить видео на YouTube.». Обязательный параметр — строка `query`. Подсказки маршрутизации: «youtube видео», «ютуб видео».

## Состояние

Заглушка, уже включённая в процесс. `Register` поднимает соединение через `protocol.Run` (флаги звука и медиа остаются выключенными). Ядро вызывает эту регистрацию из `skillRegs` в `cmd/yascore/init.go`. На вызов отвечает `protocol.NotReady`: текст «скилл youtube ещё не подключён», без ошибки.

## Разработано

- Имя скилла на шине: `youtube`.
- Один инструмент `play_youtube`, схема параметра `query` (string, required).
- Подсказки: «youtube видео», «ютуб видео».
- Обработчик — общий `protocol.NotReady("youtube")`.

## Проверено

Тестов пакета нет: в `skills/youtube` нет файлов `*_test.go`.

## Не реализовано

Поиск ролика и включение видео на YouTube. Аргумент `query` не читается, плеер не вызывается.
